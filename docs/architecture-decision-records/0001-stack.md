# ADR 0001 — статический типизированный клиент

Статус: принято, 15 ноября 2026.

TypeScript, React и Vite: небольшой статический клиент с отдельным data-driven движком. DOM/CSS для слоёв сцен и доступного интерфейса, SVG для нитей доски. Zod проверяет загружаемые данные и сохранения. IndexedDB хранит единственный ручной слот и необратимую отметку завершения одной транзакцией. Vitest — чистые функции и маршруты, Playwright — desktop UI.

Backend, аккаунты и облачные сохранения не нужны. Доступ к закрытому тестовому сайту обеспечивает Sites. Никаких секретов в клиенте. Полный Phaser/Pixi и отдельный state-machine фреймворк на первом деле не оправданы: сцены статические, а граф задан данными all/any/atLeast.

Сценарий не живёт в React-компонентах. CASE_SPEC.json остаётся авторским контрактом. Подготовка данных удаляет авторские summary и truthGuards и создаёт безопасный клиентский реестр. Суд работает только с вручную выбранными карточками; время не участвует в сюжетных переходах.

Структура: src/engine, src/cases/chuzhoe-alibi, src/features, src/persistence, src/ui, public/assets, tests и docs.

Целевые команды: npm install, npm run dev, npm test, npm run test:e2e, npm run build, npm run preview; python3 tests/validate_case_spec.py. Точные версии фиксируются lockfile при создании клиента.

Нельзя гарантировать защиту авторской истины от анализа загруженного JavaScript статической игры; требование относится к игровому интерфейсу, текстам и неверным финалам.
