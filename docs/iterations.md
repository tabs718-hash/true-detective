## 06 — суд, консультация и финальная реконструкция (0.4)

Судебные исходы разыгрываются отдельными сценами: передача материалов, рассмотрение, решение, последствия и отчёт. Только правильный исход открывает послесудебное признание и четыре кадра реконструкции. Добавлены семь оригинальных финальных эскизов; плохие исходы не показывают виновницу. Точные минуты первоначальной травмы или возвращения Ричарда не вводятся.

Правила вердикта читаются из канонического finalRules. Судебный текст и набор цитируемых карточек получают только выбранный пакет. Замечания прокурора сохраняют снимок прежнего пакета и читаются повторно без второй консультации. В оформлении дела появились поиск, фильтр типа и явный список приложений; автоматического подбора нет.

Позиция чтения финала сохраняется отдельно от ручного слота. Финальная блокировка остаётся необратимой, старый открытый экран не может перезаписать новую игру. Сейвы предыдущих версий получают значения по умолчанию для новых полей. Юридическая редактура точной квалификации и реалистичная художественная итерация остаются открытыми задачами.

Проверки: 92 локальных Vitest-теста PASS, 6 групп Python-контракта PASS, TypeScript/production build PASS; 61 SVG проверен как XML. Тесты разметки выполнялись локальным React server renderer без браузера и проверяют отсутствие запрещённых сцен, а не внешний вид. Playwright-сценарии приведены к поэтапному финалу для будущей проверки, но не запускались. В CI браузерные проверки переведены в отдельный ручной запуск, чтобы дальнейшая отправка финальной сборки не запускала их автоматически. GitHub и облачный браузер не использовались; публикация выполняется на закрытом Sites.
